================================================================================
NEXTDEPLOY — UI-ONLY FEATURES PENDING GO BACKEND IMPLEMENTATION
================================================================================
Updated: 2026-10-23
Audited across all React views (`src/features/*`, `src/lib/api/*`) and Go Fiber
backend handlers (`main.go`, `internal/handlers/*`, `internal/db/*`).

This document lists all features that are implemented in the React UI with
interactive state, modals, and user workflows, but do NOT have corresponding
endpoints or database schema support in the Go backend yet.

--------------------------------------------------------------------------------
1. EPHEMERAL PR & BRANCH PREVIEW DEPLOYMENTS (*.preview.nextdeploy.sh)
--------------------------------------------------------------------------------
- UI Location:
  `src/features/workspace/AppWorkspace.tsx` (Deployments Tab & Domains Tab)
- UI Behavior:
  - Toggle switch for "Automatic Preview URLs (Pull Requests & Branches)".
  - Filter pill in Deployments tab (`Preview URLs`) displaying isolated PR stacks
    (e.g., `pr-48-<slug>.preview.nextdeploy.sh`, `staging-<slug>.preview.nextdeploy.sh`).
  - Domain modal preview route toggle (`newDomainIsPreview`).
- Pending Go Backend Work:
  - Extend GitHub/GitLab webhook handler (`internal/handlers/panel_github.go`) to listen
    for `pull_request` (`opened`, `synchronize`, `closed`) events alongside `push`.
  - Spin up an ephemeral Docker Compose project (`docker compose -p <slug>-pr<num> up -d`)
    with dedicated ephemeral workspace directory.
  - Automatically register a dynamic Caddy wildcard/subdomain route (`*.preview.<host>`)
    and tear down the preview stack when the PR is merged or closed.

2. ONE-CLICK POINT-IN-TIME RELEASE ROLLBACK & ZERO-DOWNTIME BLUE/GREEN [DONE]
--------------------------------------------------------------------------------
- Status: Fully implemented in Go backend & React UI.
- Backend Features:
  - SQLite schema migrations: `apps.active_slot`, `apps.standby_slot`, `deploy_logs.slot`,
    `deploy_logs.commit_sha`, `deploy_logs.image_digest`, `deploy_logs.env_snapshot`,
    and `allocated_ports` table.
  - Caddy Port Gateway (`:4013`, `127.0.0.1:4013`) with `lb_try_duration: 30s` and active healthcheck.
  - Multi-tier Readiness Probe Cascade (Docker Healthcheck -> HTTP 200-399 -> TCP socket dial).
  - 30-second Connection Draining grace period before warm standby retention.
  - Backend handler `POST /apps/:id/deployments/:depId/rollback` for instant slot switch (< 100ms)
    or deep Git SHA restore.
- UI Behavior:
  - Cleaned up mock PR badges and previews as requested.
  - Active Production Slot & Zero-Downtime Status banner added.
  - 3-dot menu "Rollback to Release" wired to backend API.

3. FILE MANAGER CHMOD PERMISSIONS MATRIX (OCTAL / SYMBOLIC PERMISSIONS)
--------------------------------------------------------------------------------
- UI Location:
  `src/features/workspace/AppWorkspace.tsx` (File Manager Tab -> Context Menu -> Permissions)
- UI Behavior:
  - Interactive cPanel-style 3x3 Owner/Group/World Read-Write-Execute matrix that
    dynamically computes octal (`0755`, `0644`, `0600`) and symbolic (`-rwxr-xr-x`) modes.
- Pending Go Backend Work:
  - Add `POST /apps/:id/browse/chmod` in `internal/handlers/panel_workspace_files.go`
    accepting `{"path": "...", "mode": "0755"}`.
  - Validate against workspace path traversal (`workspaceSubpath(root, relPath)`).
  - Execute `os.Chmod(absPath, os.FileMode(parsedOctal))`.

4. FILE MANAGER MULTI-FORMAT ARCHIVE COMPRESSION (.TAR.GZ IN ADDITION TO .ZIP)
--------------------------------------------------------------------------------
- UI Location:
  `src/features/workspace/AppWorkspace.tsx` (File Manager Tab -> Compress Modal)
- UI Behavior:
  - Allows choosing between `.zip` and `.tar.gz` archive formats and entering custom
    output archive filenames.
- Pending Go Backend Work:
  - Currently `POST /apps/:id/browse/zip` (`BrowseZip` in `panel_workspace_files.go`)
    only creates `.zip` named `<source>.zip`.
  - Extend endpoint to accept optional `archive_name` and `format` (`zip` | `tar.gz`)
    parameters and write `.tar.gz` via standard `archive/tar` and `compress/gzip`.

5. HISTORICAL TIMESERIES TELEMETRY & METRICS (CONTINUOUS CPU / RAM / DISK GRAPHS)
--------------------------------------------------------------------------------
- UI Location:
  `src/features/monitoring/MonitorView.tsx` & `src/features/overview/OverviewDashboard.tsx`
- UI Behavior:
  - Interactive time-series area charts showing CPU %, Memory %, Disk I/O, Network
    Throughput (In/Out Mbps), and Requests/min over time (15m, 1h, 24h).
  - Currently generated via simulated random walk (`appendTelemetryTick`) in client state.
- Pending Go Backend Work:
  - Background ticker in `internal/handlers/monitor_collector.go` sampling Docker container
    cgroups and host /proc stats every 10–30 seconds.
  - Ring buffer or SQLite table (`metrics_history(app_id, cpu_pct, mem_mb, disk_io, net_in, net_out, recorded_at)`).
  - Endpoint `GET /api/v2/metrics/history?app_id=...&window=1h` returning historical series.

6. REMOTE GIT BRANCHES AUTO-SCANNER FOR PUBLIC GIT REPOS (WITHOUT CLONING)
--------------------------------------------------------------------------------
- UI Location:
  `src/features/workspace/tabs/ProjectGitTab.tsx` (Public Git URL mode)
- UI Behavior:
  - "Fetch Branches" button and branch dropdown datalist.
  - Currently supported for connected GitHub App / GitLab providers via provider APIs,
    but not for arbitrary Public Git URLs (`authMode === 'public'`).
- Pending Go Backend Work:
  - Add `GET /apps/:id/git/remote-branches?url=<public_git_url>` running
    `git ls-remote --heads <url>` with a 5-second timeout to return available remote branches.
