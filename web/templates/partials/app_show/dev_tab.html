Development mode

Mount the workspace into the container so code edits apply without rebuilding.

{{if .DevMode}} Enabled {{else}} Disabled {{end}}

Default skips prebuilt-image services (databases, caches). Picking a service mounts that one only — including image-only services.

Where the workspace is mounted inside the container. Must match your Dockerfile WORKDIR.

You still supply the reload command. Mounting only makes files visible — the process inside the container decides whether it picks them up. Use a watching command in your compose file, for example npm run dev, uvicorn main:app --reload, or air. Adding a new dependency still needs a normal deploy with a rebuild.

Edit over SSH

Open this app's workspace in your own editor. Saved files reach the container immediately while dev mode is on.
