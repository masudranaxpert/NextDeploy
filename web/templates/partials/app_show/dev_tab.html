Development mode

Mount the workspace into the container so code edits apply without rebuilding.

{{if .DevMode}} Enabled {{else}} Disabled {{end}}

Deploy runs up -d without rebuilding. Git apps skip repository sync, and webhook auto-deploys are paused. Redeploy still rebuilds from the current workspace (without pulling remote Git). Use Sync repository only when you intentionally want to discard local edits.

Leave blank to mount only services with a build: section (your app code). Databases and caches that use a ready-made image are left alone. Pick a specific service only if you want that one mounted — including an image-only service if you really mean it.

Must match your Dockerfile WORKDIR.

You still supply the reload command

Mounting only makes files visible — the process inside the container decides whether it picks them up. Use a watching command in your compose file, for example npm run dev, uvicorn main:app --reload, or air. Adding a new dependency still needs Redeploy.
