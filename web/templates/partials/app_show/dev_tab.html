Development mode

Live bind-mount workspace into running containers. Edits take effect immediately without image rebuilds.

{{if .DevMode}} Active {{else}} Disabled {{end}}

Mounts your workspace files directly into the container. Your code changes reflect live without Docker rebuilds.

  • Instant file sync: Workspace files are bind-mounted into your container's working directory.
  • Work protection: Automatic Git repository pulls and webhook auto-deploys are paused to prevent overwriting local code.
  • Dependency updates: When you update your Dockerfile or add system packages, use Redeploy to rebuild the container image.

Default: Mounts all application services that build from source or share built images. Supporting services like databases and Redis caches are kept isolated.

Must match the WORKDIR instruction in your Dockerfile (default: /app).
