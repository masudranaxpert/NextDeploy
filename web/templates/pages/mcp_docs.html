Connect Your AI Assistant

Choose your client below for copy-paste instructions and configuration files.

  1. In Cursor, open Cursor Settings (Ctrl+, or Cmd+,).
  2. Navigate to Features > MCP > Add New MCP Server.
  3. Enter the configuration below or edit your ~/.cursor/mcp.json directly:
{
  "mcpServers": {
    "nextdeploy": {
      "url": "{{.BaseURL}}/mcp/sse",
      "headers": {
        "Authorization": "Bearer {{if .NewToken}}{{.NewToken}}{{else}}YOUR_API_TOKEN_HERE{{end}}"
      }
    }
  }
}

Run this single CLI command from your laptop terminal to add NextDeploy to your global Claude Code configuration:

claude mcp add --transport sse nextdeploy {{.BaseURL}}/mcp/sse --header "Authorization: Bearer {{if .NewToken}}{{.NewToken}}{{else}}YOUR_API_TOKEN_HERE{{end}}"

Claude Code will automatically detect all 18 NextDeploy tools without installing Node.js or Docker on your laptop!

Add to your Windsurf configuration in ~/.codeium/windsurf/mcp_config.json:

{
  "mcpServers": {
    "nextdeploy": {
      "url": "{{.BaseURL}}/mcp/sse",
      "headers": {
        "Authorization": "Bearer {{if .NewToken}}{{.NewToken}}{{else}}YOUR_API_TOKEN_HERE{{end}}"
      }
    }
  }
}

Add to your Claude Desktop config (claude_desktop_config.json):

{
  "mcpServers": {
    "nextdeploy": {
      "url": "{{.BaseURL}}/mcp/sse",
      "headers": {
        "Authorization": "Bearer {{if .NewToken}}{{.NewToken}}{{else}}YOUR_API_TOKEN_HERE{{end}}"

Test the JSON-RPC endpoint directly from your terminal:

curl -X POST {{.BaseURL}}/mcp \
  -H "Authorization: Bearer {{if .NewToken}}{{.NewToken}}{{else}}YOUR_API_TOKEN_HERE{{end}}" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
Zero VPS Overhead

No need to run 4GB RAM Node.js or heavy AI models inside your VPS. The assistant runs locally on your workstation, sending only lightweight tool calls to NextDeploy.

No Permission or Root Issues

NextDeploy manages all file edits, named volumes, and container restarts internally. No UID/GID mismatch, root-owned file conflicts, or broad SSH access required.

Closed Development Loop

With basic SSH, agents can't trigger deploys or inspect runtime logs. With MCP, the entire loop (edit → deploy → log tail → diagnosis → hotfix) is completely automated.

Authorize external AI coding agents via MCP

Required
Quick presets:
Allow env_reveal (Expose Secrets)

Default (Safe): The assistant can list environment variable names via env_list, but secret values and passwords stay strictly masked. High Privilege: The assistant can read unmasked plaintext passwords, database URLs, and API keys via env_reveal. Enable only for trusted tools.

Allow container_exec (Container Shell)

Commands cannot be executed inside containers. Safe default for coding agents that only edit files. Allows arbitrary shell commands inside application Docker containers (container_exec). Isolated inside container workspace.

Allow server_exec (Host VPS Shell)

Shell commands on the panel host server cannot be executed via this token. Recommended. Critical: Allows arbitrary shell commands directly on the panel host server (server_exec). Only for fully trusted admin agents.
