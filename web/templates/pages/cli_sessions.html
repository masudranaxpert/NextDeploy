Install NextDeploy CLI (`nd`)

Standalone binary with zero external dependencies

Run in your terminal:

curl -fsSL https://raw.githubusercontent.com/masudranaxpert/NextDeploy/main/install-nd.sh | sh

Run in PowerShell:

irm https://raw.githubusercontent.com/masudranaxpert/NextDeploy/main/install-nd.ps1 | iex

Quick Start Commands:

nd login {{.BaseURL}} <token>  # login directly with token
nd apps                           # list accessible apps
nd link <app_id>                  # link project folder
nd push                           # diff local files & deploy
nd logs                           # stream container logs
