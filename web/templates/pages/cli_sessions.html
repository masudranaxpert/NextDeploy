Install NextDeploy CLI (`nd`)

Standalone binary with zero external dependencies

Run in your terminal:

curl -fsSL https://raw.githubusercontent.com/masudranaxpert/NextDeploy/main/install-nd.sh | sh

Run in PowerShell:

irm https://raw.githubusercontent.com/masudranaxpert/NextDeploy/main/install-nd.ps1 | iex

Quick Start Commands:

nd login {{.BaseURL}} <token>  # login directly with token
nd apps                           # list accessible apps
nd link <app_id>                  # link project folder
nd push                           # diff local files & deploy
nd logs                           # stream container logs

Quick presets:
Allow env_reveal (Expose Secrets)

Default (Safe): The CLI can list environment variable names, but secret values and passwords stay strictly masked. High Privilege: The CLI and agents can read unmasked plaintext passwords, database URLs, and API keys via env_reveal.

Allow container_exec (Container Shell / nd exec)

Commands cannot be executed inside application containers. Allows arbitrary shell commands inside Docker containers via nd exec or MCP container_exec.

Allow server_exec (Host VPS Shell)

Shell commands on the panel host server cannot be executed via this token. Recommended. Critical: Allows arbitrary shell commands directly on the panel host server (server_exec). Only for fully trusted admin agents.
